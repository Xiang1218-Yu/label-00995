# 科技园智慧财务一体化管理系统

## How to Run

### 使用 Docker Compose（推荐）

```bash
# 构建并启动服务
docker-compose up --build -d

# 查看服务状态
docker-compose ps

# 查看日志
docker-compose logs -f frontend

# 停止服务
docker-compose down
```

访问地址：http://localhost:8080

### 本地开发

```bash
# 进入前端目录
cd frontend

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 项目介绍

### 项目概述

你是一个资深的前端工程师，擅长使用Vue 3 + TypeScript + Vite + Element Plus + Pinia + Vue Router构建现代化的企业级后台管理系统。请为我创建一个完整的Vue 3前端项目：**科技园智慧财务一体化管理系统**。项目要求：- 使用Vite作为构建工具。- UI框架：Element Plus（最新版），确保UI美观、专业、响应式（支持暗黑模式可选）。- 状态管理：Pinia。- 路由：Vue Router。- 数据模拟：所有数据使用Mock（硬编码或使用Mockjs生成真实感强的假数据），无需真实后端接口。所有增删改查、审批流程等逻辑在前端模拟实现（包括本地存储到localStorage以实现持久化）。- 图表：使用ECharts展示资金统计、报销趋势等。- 布局：标准的后台管理系统布局（左侧菜单 + 顶部导航 + 主内容区），参考vue-element-plus-admin或v3-admin-vite的风格，美观大气，使用蓝色调为主（科技感）。- 登录页面：简单登录（用户名/密码硬编码，如admin/123456），登录后进入主系统。- 项目结构清晰：src/views下按模块分文件夹，components复用组件，stores分模块store。系统核心模块和页面（严格根据以下功能实现）：1. **发票夹管理**- 列表页：表格显示发票（发票号码、开票日期、金额、类型：住宿/餐饮/其他、上传人、状态：未报销/已报销），支持搜索、分页。- 新增/编辑：表单支持手动录入或“模拟上传”（显示预览），发票类型下拉选择。- 操作：删除、发起报销（跳转到报销申请并带入选中的发票）。- Mock数据：至少20条真实感发票数据。2. **汇款申请管理**- 列表页：表格显示汇款记录（汇款单位、金额、用途、日期、关联项目、状态）。- 新增/编辑表单：录入汇款信息。- 操作：删除、用于汇款报销。- Mock数据：15条左右。3. **报销管理**- 列表页：显示所有报销单（单号、申请人、类型：普通报销/汇款报销、金额、状态：待审核/已通过/已驳回、审批流程记录）。- 新增普通报销：从发票夹选择多张未报销发票，关联项目，填写说明，提交后状态变为“待审核”。- 新增汇款报销：选择已登记汇款，填写报销详情。- 详情页：显示报销单详情、关联发票/汇款、审批历史（模拟多级审批：部门负责人→财务→园区领导）。- 操作：审批（通过/驳回，更新状态并添加审批意见）。- Mock数据：多种状态的报销单。4. **津贴发放管理**- 人员名单维护：表格管理发放人员（姓名、部门、标准金额）。- 发放规则配置：支持不同类型津贴规则（固定金额、按项目计算等）。- 发放记录列表：显示历史发放（人员、金额、时间、方式）。- 新增发放：批量或单个发放，记录生成。- Mock数据：人员名单20人，历史记录。5. **薪酬申报管理**- 申报列表：显示申报记录（月份、申报人、总金额、状态）。- 新增/编辑申报：表格形式填写员工薪酬（姓名、基本工资、绩效、扣款等），自动计算合计，支持校验。- 生成报表：支持导出Excel（使用xlsx库模拟导出）。- Mock数据：最近几个月申报。6. **薪酬发放管理**- 发放列表：关联申报数据，显示发放记录。- 操作：确认发放、查询、打印（模拟打印）。- 工资条详情：员工工资结构明细。7. **资金管理**- 资金概览仪表盘：卡片显示各类资金总额、已到款、已使用、剩余（使用ECharts饼图/柱状图展示）。- 资金列表：不同类型资金（扶持资金、建设经费、运营经费）的明细、使用记录。- 使用记录：关联到报销、薪酬等，展示资金流向。- 图表：资金使用趋势折线图。额外要求：- 主仪表盘首页：展示系统概览（总资金、待审批报销数、近期津贴发放、薪酬统计），使用卡片 + ECharts图表，美观大方。- 所有表格支持搜索、排序、分页、导出CSV。- 表单验证完整（Element Plus自带）。- 权限模拟：菜单根据角色显示（管理员全显，普通用户部分）。- 真实展示数据：所有Mock数据要真实感强（真实公司名、项目名如“科技孵化项目A”、金额合理、日期近期）。- 代码规范：使用Composition API + <script setup>，TypeScript类型完整，注释清晰。- 响应式：支持移动端简单查看。请先生成完整的项目结构和package.json，然后逐步生成每个模块的代码（路由、store、视图、组件）。如果一次生成太多，可以分步输出，但最终提供可直接运行的完整代码。

### 核心功能模块

#### 1. 发票夹管理
- 发票列表展示（发票号码、开票日期、金额、类型、上传人、状态）
- 支持搜索、分页、排序、导出
- 新增/编辑发票（支持手动录入和模拟上传）
- 删除发票、发起报销

#### 2. 汇款申请管理
- 汇款记录列表（汇款单位、金额、用途、日期、关联项目、状态）
- 新增/编辑汇款申请
- 删除汇款、用于汇款报销

#### 3. 报销管理
- 报销单列表（单号、申请人、类型、金额、状态、审批流程）
- 新增普通报销（从发票夹选择多张发票）
- 新增汇款报销（选择已登记汇款）
- 报销详情页（显示详情、关联发票/汇款、审批历史）
- 多级审批流程（部门负责人→财务→园区领导）

#### 4. 津贴发放管理
- 人员名单维护（姓名、部门、标准金额）
- 发放规则配置
- 发放记录列表（历史发放记录）
- 批量或单个发放

#### 5. 薪酬申报管理
- 申报列表（月份、申报人、总金额、状态）
- 新增/编辑申报（表格形式填写员工薪酬）
- 自动计算合计、数据校验
- 导出 Excel 报表

#### 6. 薪酬发放管理
- 发放列表（关联申报数据）
- 确认发放、查询、打印（模拟打印）
- 工资条详情（员工工资结构明细）

#### 7. 资金管理
- 资金概览仪表盘（卡片展示 + ECharts 图表）
- 资金列表（不同类型资金的明细）
- 使用记录（关联到报销、薪酬等）
- 资金使用趋势折线图
